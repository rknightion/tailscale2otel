tailscale2otel · m7kni design system v2

Embedded console restyle, and the 2otel family visual layer

Seven screens, each as a light / dark pair. Light is the new default; dark stays first-class and keeps the existing data-theme toggle and its localStorage key. Information architecture, tab set, ARIA roles and terminology are unchanged. The token block behind these screens is the one all four consoles share byte-identically - it is reproduced in the implementation spec.
