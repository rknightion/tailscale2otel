3d

ifIndex tab

Mono-dominant, read straight down against ifinfo. Row markers replace row tints.
A NetFlow ifIndex is a 1-based position over /usr/local/sbin/ifinfo output, which OPNsense turns into the netgraph hook name ifaceN. It is not an OS or SNMP index and nothing pins it: adding or removing any interface renumbers every interface after it. Compare this table straight down against ifinfo on the firewall after any interface change. The exporter can only derive this mapping, so a silent divergence here mislabels every flow. Loads on demand, not on the auto-refresh poll. Reload
